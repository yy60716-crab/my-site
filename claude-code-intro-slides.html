Step 1 · 只做一次

初始安裝

  1. 按 Win + R，輸入 powershell，按 Enter
  2. 貼上並執行安裝指令： 
    irm https://claude.ai/install.ps1 | iex
  3. 依畫面指示登入 Claude 帳號
[截圖位置：PowerShell 安裝過程畫面]

常見狀況：裝好了，但打 claude 沒反應

這是「安裝成功，但指令找不到」——電腦不知道去哪找 claude.exe，不是壞掉。原因是安裝資料夾沒有被加進 PATH。

  1. 永久加入 PATH（做一次就好；記得把路徑裡的帳號換成自己的）： 
    [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";C:\Users\HP\.local\bin", "User")
  2. 關掉 PowerShell、重新開一個（PATH 要重開才生效）
  3. 再打 claude，就會動了

想在「目前這個視窗」馬上試、不想重開：$env:Path += ";C:\Users\HP\.local\bin"（只在這個視窗有效，要永久生效仍要做上面第 1 步）

切換方式：Shift + Tab

三種工作模式

Auto mode

預設、最常用

Plan mode

先分析規劃再動手，適合寫網站這類較大的任務

Dangerous mode

Claude 完全自由執行、不逐一確認

新手先不要用

按 Shift + Tab 依序切換這三種模式。

參考資料

Claude Code 常見權限提示說明表

看到權限提示時，名稱＝Claude 想使用的工具。判斷原則：唯讀類可放心允許；會改動檔案或執行指令的，看內容再決定；MCP 看是哪個服務的哪個動作。整理日期：2026-07-15

權限名稱做什麼類型風險建議
Read 讀取檔案內容 唯讀 低 可放心允許。只能看、不能改。
Glob 用檔名模式找檔案（如 *.docx） 唯讀 低 可放心允許。只列出檔名清單。
Grep 在檔案內容中搜尋關鍵字 唯讀 低 可放心允許。只回傳符合的文字行。
Write 建立新檔案或整份覆寫 寫入 中 看它要寫哪個路徑：新檔案通常沒問題，覆寫舊檔要留意。
Edit 修改既有檔案的部分內容 寫入 中 看它要改哪個檔、改什麼。重要文件建議先備份。
PowerShell / Bash 執行終端指令（跑程式、裝套件、刪檔、改設定都可能） 執行 高 務必看指令內容再決定。你的設定已預設 shell 指令一律詢問。
WebSearch / WebFetch 搜尋網路／抓取網頁內容 網路（讀） 低–中 查資料用，基本安全；留意是否抓取奇怪網址。
Agent / Task 派出子代理執行搜尋或多步驟任務 委派 中 子代理仍受相同權限管制；通常可允許。
Skill 呼叫技能（如 /discord:access、pdf、xlsx） 依技能而定 依技能 看技能名稱：存取控制類（access/configure）要自己在終端跑。
MCP：discord reply / react / edit_message 回覆 Discord 訊息、加表情、編輯訊息 外部服務（發送） 中 內容會發到 Discord；確認訊息對象與內容合理。
MCP：discord fetch_messages 讀取 Discord 歷史訊息 外部服務（讀） 低 唯讀，可允許。
MCP：discord download_attachment 下載 Discord 附件到本機 外部服務（下載） 中 受頻道允許名單管制；要開放需在終端跑 /discord:access。
Artifact 把檔案發佈成 claude.ai 網頁 對外發佈 中–高 內容會上雲端（預設私人）；敏感內容不要發佈。

備註

一、權限模式可在終端用 Shift+Tab 切換（一般／自動接受編輯／計畫模式）。
二、常用且安全的工具可加入允許清單（settings.json），之後不再逐次詢問——回終端叫 Claude 幫你設定即可。
三、透過 Discord 遠端操作時，任何權限提示都會等你在 Discord 上按允許／拒絕，拒絕不會中斷對話。

進階

Skills（推薦安裝）

  • Skill = 給 Claude 的工作手冊，教它照你的流程做事
  • 安裝方式：把 skill 的網址直接貼給 Claude Code，請它安裝到「家」目錄（home）
  • 好處：裝在家目錄後，同一位使用者的所有專案都能使用

課後複習

課後小練習 & 指令總表

  1. 自己完成安裝並登入
  2. 在任一資料夾啟動 claude，請它列出這個資料夾裡有哪些檔案
  3. 用 Shift + Tab 把三種模式各切換一輪，最後停在 Auto mode
指令 / 快捷鍵功能什麼時候用
irm .../install.ps1 | iex安裝 Claude Code第一次設定電腦時（只做一次）
SetEnvironmentVariable(...)把安裝資料夾加進 PATH打 claude 出現「無法辨識」時
claude啟動 Claude Code每次要開始工作時
Shift + Tab切換 Auto / Accept Edits / Plan 模式想改變 Claude 的執行方式時
claude --dangerously-skip-permissions啟動 Dangerous（Bypass Permissions）模式只在完全了解風險、且在隔離環境時使用
Shift + 右鍵在 PowerShell 貼上文字要貼指令或文字到終端機時
/叫出斜線指令選單忘記指令時
/usage查看用量想知道自己用了多少額度時
/model切換模型想換用不同模型時
/plugins安裝與管理插件想串接 Telegram、Discord 等服務時
@選取檔案帶進對話想針對特定檔案討論時
Esc中斷 Claude 正在進行的動作方向錯了，想先喊停時
Alt + V貼剪貼簿圖片給 Claude Code想直接貼截圖給 Claude 看時
claude -h查看說明（help）忘記啟動參數時
claude -c接續上一次的對話想接著上次沒講完的任務時
claude -r列出更多歷史紀錄，挑一個繼續想回到更早之前的某次對話時
