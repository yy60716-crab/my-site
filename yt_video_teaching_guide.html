Claude Code · /watch 插件教學

用 YouTube 影片做教材
完整安裝教學

給完全沒裝過任何工具的人。全程在 Windows 的 PowerShell 操作，照著打就好，大約 15–20 分鐘。裝好之後，貼一個網址，Claude 就能同時「看畫面」又「聽內容」，幫你整理出一份教材。

畫面（投影片、圖表、字卡）
＋

→
Claude 讀得懂的教材
先建立觀念

這套工具在做什麼？

一支影片其實只有兩層東西：畫面（投影片、圖表、數據、螢幕字卡）和聲音（講者說出來的話）。大多數「影片摘要工具」只抓聲音那一層，畫面上的重點——一張趨勢圖、一個數字、一句字卡——全部漏掉。

這套流程兩層都抓：

  1. 用 yt-dlp 把影片下載下來
  2. 用 ffmpeg 在畫面變化時截圖（等於自動抓下每一頁投影片）
  3. 拿到逐字稿（有字幕直接用；沒字幕才需要另外處理，見下方「沒字幕怎麼辦」）
  4. 把「截圖 ＋ 逐字稿」一起交給 Claude

一句話：別的工具讓 Claude「讀」影片，這套讓 Claude「看」影片。

開始前

兩個貫穿全程的觀念

裝完一定要「關掉重開」

每次用 winget 裝完一個工具，都要把 PowerShell 完全關掉、重新開一個，新裝的工具才叫得出來。系統靠一份叫「PATH」的清單記得「哪些工具可以直接呼叫」，已經開著的視窗還在讀舊清單。

🔑 之後只要看到「無法辨識 XXX」的錯誤，第一個動作永遠是：關掉 PowerShell、重開、再試一次。九成的問題都是這個。

怎麼打開 PowerShell？

方法一：按左下角 開始鍵（⊞），打 PowerShell，點藍色圖示。
方法二：按 Win + R 打開「執行」視窗，輸入 powershell，按 Enter 或按「確定」。

打開後會看到一行像這樣，之後指令都打在 > 後面，打完按 Enter：

PowerShell
PS C:\Users\你的名字>
安裝流程

五個步驟，裝好整套工具

每一步裝完都要「關掉 PowerShell、重新開一個」再繼續下一步。

1

安裝 yt-dlp 和 ffmpeg

整套工具的「引擎」——一個負責下載影片，一個負責處理影音、截圖。

PowerShell
winget install yt-dlp.yt-dlp
PowerShell
winget install Gyan.FFmpeg

看到最後一行 Successfully installed 就是成功了。中途跳出「是否允許以系統管理員身分執行」按「是」即可。

裝完關掉重開後確認：
確認版本
yt-dlp --version
ffmpeg -version
會分別看到版本號，像 2025.06.30 和 ffmpeg version 7.x ...。
2

安裝 git

等一下的 watch 插件放在 GitHub 上。要把 GitHub 上的東西抓到電腦，需要 git 這個「搬運工」，少了它裝插件那步會直接報錯。

PowerShell
winget install Git.Git
裝完關掉重開後確認： 
git --version
會看到像 git version 2.55.0.windows.2。
3

在 Claude Code 裡安裝 watch 插件

關鍵區別：凡是開頭有斜線 / 的指令（像 /plugin、/watch），都是打在 Claude Code 裡面，不是打在 PowerShell。先打 claude 進入 Claude Code 的介面，PowerShell 不認得斜線指令，打了會出錯。

確認你人在 Claude Code 裡（不是 PowerShell），依序打這兩行：

Claude Code
/plugin marketplace add bradautomates/claude-video
Claude Code
/plugin install watch@claude-video

第一行＝告訴 Claude Code「這個開源專案是可信的貨源」；第二行＝把 watch 插件真正裝進來。過程中會問「裝給誰用」，選第一個：

選這個Install for you (user scope) — 個人自用，跨資料夾都能用
Install for all collaborators (project scope) — 團隊共用才需要
Install for you, in this repo only (local scope) — 只在單一資料夾

它也會顯示驚嘆號警告「Anthropic 不控管第三方插件」——這是所有插件的公版提醒，不用擔心。

裝好後讓插件生效： 
/reload-plugins
看到 Successfully loaded skill 就代表啟用了。
4

第一次設定

第一次載入插件時，會問兩個問題：

5-1　Whisper API key（語音轉逐字稿）——選 「No key, skip for now」。這把 key 只有影片完全沒字幕、要拿聲音轉逐字稿時才用得到；有字幕的影片（多數 YouTube 影片）用不到，先跳過完全不影響，之後常遇到沒字幕影片再申請也來得及。

5-2　Detail level（要截多少畫面）——選 「balanced (recommended)」。

選項意思適合
efficient最多 50 張，快只要大概摘要
balanced場景變化才截，最多 100 張做教材（推薦）
transcript完全不截圖，只要逐字稿不需要畫面時
token-burner張數無上限，最完整也最貴要看每個畫面細節
5

開始使用

在 Claude Code 裡，貼上影片網址加你的問題：

語法
/watch 影片網址 你想問的問題

看整支影片：

/watch https://www.youtube.com/watch?v=影片ID 幫我整理這支影片的重點，包含講者說的內容和畫面上的資訊

只看某一段（省時間）：

/watch https://www.youtube.com/watch?v=影片ID --start 00:35 --end 01:30 分析這一段

它會自動：下載影片 → 截圖 → 抓逐字稿 → 把畫面和文字讀進去 → 回答你。第一次跑要下載影片會花一點時間，畫面一直捲動是正常的。

沒有官方字幕怎麼辦

影片沒字幕，還是能做出教材

貼上網址後發現逐字稿是空的、或 /watch 提示這支影片沒有字幕？不需要申請 Whisper key，有兩條路可以走。

方法 A

純靠畫面重建

最快、免申請任何 key

/watch 本身就會截圖，沒有字幕不影響截圖這件事。直接照平常的方式問，讓 Claude 單靠畫面（投影片、圖表、新聞截圖、字卡）重建重點。

  1. 照常打 /watch 影片網址 你的問題
  2. 心裡預期「這次沒有逐字稿可以核對」
  3. 問題盡量具體，例如請它列出畫面中出現的數字、圖表、關鍵字卡
適合：投影片、圖表、新聞截圖、字卡資訊量大的影片。
限制：講者純口述、畫面沒什麼字或圖的段落會遺漏，無法 100% 還原逐字內容。下方〈成功案例〉就是用這個方法做出來的。
方法 B

轉逐字稿再交給 Claude

較完整、免 key，但要跑兩個網站

用 TurboScribe 把音訊轉成逐字稿，再連同截圖一起交給 Claude 整理。

  1. 下載音訊存成 mp3：
    PowerShell
    yt-dlp -x --audio-format mp3 -o "%(title)s.%(ext)s" 影片網址
  2. 到 TurboScribe 上傳這個 mp3，選中文，等它跑完下載逐字稿（txt）
  3. 把逐字稿貼給 Claude，附上想問的問題，需要的話也可以把 /watch 截到的畫面一起附上：
    這是一支影片的逐字稿，請幫我整理重點，並標出重要數字和結論
[貼上逐字稿內容]
適合：訪談、Podcast、純講述型影片，講者內容比畫面重要。
限制：多一道手動步驟，速度較慢；TurboScribe 免費額度有限，超過需要付費。
成功案例 · 真實測試結果

這是用「方法 A：純靠畫面重建」實測的結果，沒有經過任何潤飾，直接呈現 Claude 產出的內容結構。

之後想補 Whisper key 該怎麼做？

常遇到沒字幕的影片，想要更精確的逐字稿，可以去 Groq 或 OpenAI 申請一組 API key，再回到 Claude Code 用插件的設定流程補上即可，不需要重新安裝整套工具。
